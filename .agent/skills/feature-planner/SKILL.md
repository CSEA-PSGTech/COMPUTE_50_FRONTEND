# Feature planner
1. Read `AGENTS.md` and the `/docs` files relevant to the feature.
2. Inspect the existing code the feature touches.
3. Output a plan with: requirement restated, files to change/create, DB changes, API changes, security considerations, edge cases, tests to add, risks, and a step list of small tasks.
4. List open questions. Do not write code until the user approves.
